# 后续迭代路线

当前 MVP 的验收范围是可复现的本地模拟与合成像素闭环。下一阶段的首要瓶颈是真实感知和模型误差，而不是网络规模。

| 阶段 | 具体工作 | 通过标准 |
| --- | --- | --- |
| A：真实输入 | 固定分辨率与八卡组，收集完整对局；标注手牌、圣水、时间、塔血、单位类别/阵营/位置 | 留出的整场视频上逐字段测准确率、漏检率、端到端延迟；不只抽选容易帧 |
| B：感知融合 | 对局阶段识别、数字 OCR、手牌多模板/分类器、单位 HP、检测追踪、出牌事件确认 | 不把遮挡新轨迹当新下牌；连续帧 ID 稳定；低置信输入可回退等待 |
| C：动力学校准 | 用录像测 12 卡移动、攻击、出场延迟、法术与塔伤；增加碰撞、锁定和建筑拉扯 | 对单卡推进、常见防守、群体和法术交互做真实/模拟轨迹与塔伤对照 |
| D：搜索增强 | 敌方卡组与圣水后验，多候选响应，多步我方动作，时间预算、beam/MCTS | 在冻结测试集合及多个对手策略上配对改进，记录超时和非法率 |
| E：模仿学习 | 搜索教师/人类专家训练候选网络，独立编码等待/出牌与位置 | 出牌帧准确率、动作延迟、胜率和推理时间共同改善 |
| F：强化学习 | Gymnasium 适配、高保真环境、多对手、自博弈与策略版本池 | 多随机种子和未见对手评估；不能只刷单一规则对手 |
| G：真实动作验收 | 单局状态重置、动作确认、防重复下牌、断连恢复、延迟预算 | 实际设备上每个动作能被确认；未知画面可靠等待 |

建议固定八卡组直到 A–C 验收。可以替换 `Arena` 为经过复测的开源 C++ 引擎，同时保留 `Observation/Decision`、配对实验与日志接口；替换后需要重跑基线，不能沿用当前 75% 模拟胜率。

论文项目方向可聚焦一个可量化问题：感知不确定性对防守质量的影响、不同敌方信念估计下的鲁棒搜索、搜索教师到快速策略的蒸馏、或视觉事件与四卡轮转联合建模。每个方向都应建立独立的失败场景与冻结测试集。
