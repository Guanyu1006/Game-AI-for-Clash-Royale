建议操作顺序

  1. 按运行教程启动 VM、游戏探针和本页服务。
  2. 新建原生局，先暂停并单步观察。
  3. 选择己方手牌，点击标定战场或输入坐标。
  4. 核对实际消费，继续推进到终局。
  5. 保存归档，再切换到原生引擎回放。

此服务进程共享一条原生对局。多人打开页面时，请约定一个操作人。网络异常后先读取状态核对，本页不会自动重发下牌、重置或重演请求。

本页不连接官方服务器。原生画面、探针研究字段与公平策略输入的范围不同；普通单位的像素可见性认证和策略棋力须另行验证。
