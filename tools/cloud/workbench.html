在终端中训练和验证

.venv-cloud/bin/python tools/cloud/workspace.py test
.venv-cloud/bin/python tools/cloud/workspace.py train --epochs 2
.venv-cloud/bin/python tools/cloud/workspace.py train-gru --epochs 2
.venv-cloud/bin/python tools/cloud/workspace.py runs

输出保存在 outputs/cloud/runs/，每次生成独立目录。使用报告中的 checkpoint 路径运行 infer --checkpoint 和 evaluate --checkpoint；GRU 对应 infer-gru 和 evaluate-gru。默认只验证 validation，不用 test 调参。

两个人一起操作

由创建 Codespace 的人打开 Live Share 并点 Share，同学用自己的账号加入。共享终端时先约定谁运行训练。网页通过 VS Code 的 Ports 面板打开，保持端口为 Private。

现有 Windows 入口 run_play.ps1 / run_platform.ps1 继续保留。原生批量对战需要另备固定资源、Android/Binder 和经过验证的运行权限。
