# 第三阶段执行计划

规格：根目录 CODEX_PHASE3_PROMPT.txt。旧模型、平台、正式回放验收用途及历史证据全部保留。

依赖顺序：
1. 核实环境/版本/分母；修正第6项共用推理，另存新基线指标。
2. 并行第1项观测契约、第2项八卡动作与原生自采、第7项三来源适配。
3. 统一0.5秒控制；事件与执行反馈分离；整局分组冻结；小样本端到端后扩大。
4. 单帧A、可信观测B、记忆C、条件位置D、预测辅助E；至少运行真实训练、保存和新进程加载。
5. 第8项对手头，第9项一步/open-loop世界预测；预测门槛未过则禁止正式想象训练。
6. 蒸馏、原生smoke、配对评估、完整对局画面、中文教程、动态验收。

预算：现有CPU Torch优先复用，不全局安装；本机32逻辑CPU，Torch 2.14.1+cpu，无可用CUDA；D盘初查约24.99GB空闲。
本轮先用小型网络与单实例串行；新增数据/依赖预算1GB（来源先小样本）；原生采集目标50独立整局/2000次确认出牌，validation/test各10整局。初始原生墙钟预算2小时，分批可恢复；未达报告差额，不复制凑分母。

恢复入口与实际结果随运行写STATUS、DECISIONS、BLOCKERS及outputs/phase3；状态文件本身不构成验收。
