# 独立联赛验收与中断恢复证据

本目录保存正式三模型验收的原始小型文件与 SHA256 清单；大权重仍保存在项目模型交付位置。结果适用于固定版本模拟器，不代表国际服或真实设备验收。

每个对手组 50 局、25 个独立种子，双方座位；每个模型 150 局，全部自然终局，无故障、截断或拒绝。PPO 未通过冻结晋升标准，joint 诊断也未通过；foundation 不变。完整解释、吞吐与下一步见 [正式验收说明](../../../../arena_lab/ACCEPTANCE_ZH.md)。

证据结构：

- `execution-plan.json`、`promotion-template.json`、`promotion-cases.json`：执行前冻结的模型 SHA、环境身份、源码 SHA、种子矩阵、预算与门槛。
- `foundation/`、`joint/`、`ppo/`：三个冻结分组的完整计划、逐局回执及其哈希摘要；`report.json` 是原样最终报告。
- `pool.json`：独立验收池与真实执行的 PPO 晋升判定，和训练池分开。
- `selfplay/`：24 局训练的原始计划、三轮回执、报告与历史训练池；训练恢复文件只记录 SHA，不复制大文件。
- `interrupted-ppo/`、`interruption-audit.json`、`recovery-comparison.json`：原样保留的 100 局中断现场、恢复前核验与恢复后逐条对照。
- `frozen_source/`：本轮执行的七个源码文件原始字节快照，以 `.txt` 保存；不从后来修改过的工作区推断本轮实现。
- `resource-context.json`、`resource-samples.jsonl`、`logs/`：同机负载、资源快照、原始准备／运行／恢复日志。
- `package.json`、`verify.py`：逐文件 SHA 与标准库校验入口。

中断后完整两臂未重跑；PPO 原 100 局先归档，再用原冻结程序重跑完整 150 局。重复案例除墙钟时间外的所有已存字段一致。保存的自然终局回执总数是 550 条，正式独立“模型—案例”组合仍为 450；没有把重复开销增加到统计样本中。回执记录动作计数与终局状态，没有记录逐帧动作序列。

正式 450 局共 236,366 控制步、1,004.215 秒（逐局计时），235.37 步／秒、117.61 倍模拟时间；重复部分额外 234.508 秒。计时包含每局 reset 和策略加载，期间还有单线程像素训练及短时复核，属于有负载的实测。停机间隔、可能未写出回执的在途局不包含在上述数字内。
